# Евалуација (за поглавјето во трудот)

Резултатите се во `results/`. Се генерираат автоматски:

```bash
cd backend
./mvnw spring-boot:run -Dspring-boot.run.profiles=evaluation
```

Базата (Docker) мора да работи, а 5-те градови мора да имаат преземени места и внесени
Wikivoyage извори (види главниот README). Кои делови се извршуваат се подесува во
`backend/src/main/resources/application-evaluation.yml`.

## Што се мери

### 1. Алгоритам за план (`results/algorithm.md`)
Код: `backend/.../evaluation/AlgorithmEvaluation.java`

- **Редослед во денот**: должина на рутата кај случаен редослед, nearest neighbor,
  nearest neighbor + 2-opt и оптималното решение (brute force, сите 7! = 5040 редоследи).
  Покажува колку 2-opt се доближува до оптималното и колку е побрз.
- **Групирање по денови**: вкупно пешачење кај случајна поделба, поделба по оценка
  и k-means. Покажува зошто е потребно групирање по близина.

### 2. RAG пребарување (`results/rag_retrieval.md`)
Код: `backend/.../evaluation/RagEvaluation.java`, прашања: `backend/src/main/resources/evaluation/rag_questions.csv`

- 25 туристички прашања (5 по град) со очекуван дел од Wikivoyage + 5 прашања надвор од темата.
- **Hit@1, Hit@5, MRR**: дали пребарувањето го наоѓа точниот дел.
- **Праг на сличност**: табела што покажува зошто е избран прагот 0.55 (сите туристички
  прашања добиваат одговор, сите прашања надвор од темата се одбиени). Внимание: множеството
  е мало (30 прашања), па во трудот ова треба да се спомене како ограничување.
  Дополнителна заштита: и кога пребарувањето ќе пронајде текст, prompt-от му налага
  на моделот да одбие ако контекстот не го содржи одговорот.

### 3. Одговори со и без RAG (`results/rag_answers.csv`) — РАЧНА ОЦЕНКА
За секое прашање има одговор СО RAG и БЕЗ RAG (истиот модел, без контекст).

1. Отвори го фајлот во Excel (раздвојувач е `;`).
2. Во колоните „оценка“ внеси: **2** = точно, **1** = делумно точно, **0** = погрешно или измислено.
   За прашањата надвор од темата: 2 ако ботот одбил да одговори, 0 ако одговорил.
3. За проверка на точноста користи ги линковите до Wikivoyage.
4. Во трудот: просечна оценка со RAG наспроти без RAG, и број на измислени одговори (оценка 0).

Напомена: одговорите на LLM не се секогаш исти, па при повторно извршување бројките може малку да се разликуваат.

# Евалуација на алгоритмот за план

Сценарио: 3 дена × 7 атракции на ден, сите интереси. Растојанијата се воздушни (haversine),
збир за сите денови во градот. „Отстапување“ = колку % е подолга рутата од оптималната.

|---|---|---|---|---|---|---|
| Охрид | 25.44 | 13.27 | 12.24 | 12.24 | 8.4% | 0.0% |
| Скопје | 6.49 | 4.07 | 3.67 | 3.67 | 11.0% | 0.1% |
| Париз | 7.19 | 4.13 | 4.00 | 4.00 | 3.2% | 0.0% |

Вкупно за сите градови: NN отстапува 8.1%, NN + 2-opt отстапува 0.0% од оптималното.

Просечно време по ден (12 денови, по 7 места):
- Nearest neighbor: 0.015 ms
- Nearest neighbor + 2-opt: 0.079 ms
- Brute force (оптимално, 5040 редоследи): 5.376 ms
